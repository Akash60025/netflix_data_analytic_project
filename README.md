# Netflix Movie Data Analysis Project

## Project Overview

This project focuses on analyzing Netflix movie data using Data Analytics and Data Science techniques. The objective is to extract meaningful insights from a dataset containing over 9,000 movies and help support data-driven business decisions. The analysis explores movie genres, popularity, ratings, voting patterns, and release trends.

---

## Business Problem

Netflix relies heavily on Data Science, Artificial Intelligence (AI), and Machine Learning (ML) to understand customer behavior and improve recommendations. This project aims to answer important business questions such as:

* What is the most frequent genre on Netflix?
* Which movie has the highest average vote?
* Which movie has the highest popularity and what is its genre?
* Which movie has the lowest popularity and what is its genre?
* Which year has the highest number of movies released?
